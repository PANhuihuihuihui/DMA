总览中文 PPT竞品库平台痛点原始长报告

Platform research + user complaints

真实用户抱怨，决定产品边界。

本地商家的核心痛点不是“缺一个按钮”，而是：不知道发什么、没时间持续发、不信 vanity metrics、讨厌低质量营销服务商。LocalPilot 的功能选择必须从这些痛点反推。

四个平台不是同一种内容

FacebookMVP first

本地社区、活动、优惠、熟人信任

内容形态：offers、updates、events、testimonials、本地故事

成功指标：comments、shares、messages、event responses、calls、link clicks

API 现实：Meta 官方 API 可行，但需要 business account、permissions、app review、token handling。

LocalPilot 策略：最适合先验证官方发布闭环。

InstagramPhase 2

视觉发现、品牌印象、生活方式 proof

内容形态：Reels、Stories、before/after、behind-the-scenes、carousel

成功指标：saves、profile visits、DMs、Reels reach

API 现实：通过 Meta/Instagram Graph API 可做部分 publishing，但账号类型和媒体限制需要处理。

LocalPilot 策略：适合作为视觉 proof，不一定第一天做深。

TikTokSecond

娱乐发现、趋势、真实感、老板/员工人格化

内容形态：短视频 hook、老板出镜、服务过程、trend adaptation、字幕脚本

成功指标：watch time、completion、shares、comments、profile visits

API 现实：Content Posting API 支持 Direct Post / Upload-to-Draft，但视频素材、权限和审核更复杂。

LocalPilot 策略：先生成 script/caption/shot list，再做发布。

小红书 / REDDeferred / assisted

搜索、攻略、生活方式决策、华人消费信任

内容形态：笔记、合集、对比、真实体验、关键词、收藏型 carousel

成功指标：saves、search rank、comments、KOC credibility

API 现实：第三方公开发布能力有限；官方更多围绕广告、蒲公英和商业生态。

LocalPilot 策略：不是 MVP 自动发布；后续做 assisted publish + 中文内容模块。

“I need to build a following on social media (Instagram, Facebook, and TikTok), but I absolutely SUCK at social media. Reddit r/smallbusiness对营销服务商/冷邮件反感
“Every single day my inbox gets flooded with emails... You scraped a contact email from our website or a directory and blasted out the same template to thousands of businesses... Small business owners already spend half their day dealing with real operational problems.”Dear SEO company vultures · post 1rrz5ly · 292↑ / 126 comments

产品启发：GTM 不要靠垃圾 outbound；用 demo、case study、opt-in pilot。禁用‘I noticed your…’式话术。

Reddit r/smallbusiness虚荣指标没有业务价值
“Total spent: $150. Total posts: 6. Total likes: ~3500. Total comments: ~500. Visitors in page: 0. Conversions: 0. It's literally bots. Bots everywhere.”Buying posts on linkedin pages just opened my eyes · 454↑

产品启发：必须把内容连接到 calls / bookings / DMs / coupons / walk-ins；不要只报 likes/views。

Reddit / SMB threadsburnout / 持续性困难
“How do you handle social media without burning out? / How do you keep up with posting? / Anyone else finding social media harder than expected?”2026 high-engagement SMB pain threads

产品启发：主价值主张是节省时间和持续执行，不是功能堆砌。

小红书小店想用 AI 但不会用
