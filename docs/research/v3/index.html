商业判断

LocalPilot 的护城河不是“生成能力”，而是本地经营闭环。

Predis、Buffer、Canva、Hootsuite 都可以生成或排期内容；但本地老板真正需要的是：这周该发什么、发到哪里、我能不能先看一眼、发了以后有没有电话/预约/私信/优惠券/到店。

1. 业务意图老板输入促销、服务、产品或活动。
2. 平台策略Facebook 社区信任，TikTok 短视频 hook，小红书收藏型笔记。
3. 老板审核owner-in-the-loop 是信任机制，不是摩擦。
4. 官方发布优先 Facebook；TikTok 其次；小红书 assisted。
5. 结果反馈calls、DMs、bookings、coupon、walk-ins。

为什么这个机会存在

社交平台已经成为本地发现入口，但本地商家没有 marketer。AI 降低了内容生成成本，却也制造了大量低质量 AI spam。真正未被解决的是“持续、正确、能带来生意的营销执行”。

用户抱怨显示三件事：不知道发什么、没有时间持续发、不相信虚荣指标。这正好对应 LocalPilot 的三件产品能力：strategy engine、weekly autopilot、attribution loop。

一句话定位

LocalPilot AI 帮助本地商家把一个促销、服务、产品或内容想法，自动转成 Facebook / TikTok / Instagram / 小红书等平台适配内容，经商家确认后发布，并最终把帖子效果连接到电话、预约、私信、优惠券和到店转化。
