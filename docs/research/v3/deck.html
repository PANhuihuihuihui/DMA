LocalPilot AI 商业全景研究

给 co-founder 的高密度中文 deck：市场、用户痛点、平台策略、竞品、MVP 与拍板问题。

不要做 AI 发帖工具。做本地商家的 AI Marketing Operator。

核心闭环

业务意图 → 内容 → 发布 → 结果

一个促销/服务/产品想法，转成平台原生内容，经老板审核后发布，并追踪电话、预约、私信、优惠券、到店。

第一阶段

Facebook first

先验证最短闭环：官方账号连接、老板批准、正式发布、轻量 attribution。

不是 scheduler

卖结果，不卖工具

Buffer/Hootsuite 已经很多；LocalPilot 要解决“不知道发什么 + 发了有没有客户”。

产品启发

  • 不要从空白编辑器开始，要从 campaign idea / offer / service 开始
  • 不要宣传“生成更多内容”，要宣传“每周持续帮你执行”
  • 不要报 likes/views，要报 calls / DMs / bookings / coupons
  • 不要做垃圾 outbound；用 demo、case、pilot，让老板 opt-in

产品定义：LocalPilot = 本地商家的 AI Marketing Operator

1. Business Profile

行业、位置、服务、价格、语言、品牌语气、营业时间、季节性。

2. Campaign Input

老板输入一个促销、服务、产品、活动或照片/视频素材。

3. Platform Strategy

同一目标，按 Facebook/TikTok/IG/XHS 重写逻辑。

4. Owner Approval

老板审核、改字、批准；这是信任机制，不是摩擦。

5. Official Publish

优先 Facebook 官方发布；其他平台按 API 难度推进。

6. Attribution

unique URL/QR/coupon/call/message/booking/walk-in feedback。

不是

  • 通用 scheduler
  • AI caption generator
  • 全自动垃圾发帖机器人

是

  • 业务目标驱动
  • 平台原生策略
  • 老板参与审核
  • 结果反馈学习

MVP 核心样例

“这个周末 HVAC tune-up 做 $89 优惠” → FB 社区帖 + TikTok 脚本 + IG caption + tracking CTA。

GTM 与定价：先高接触 pilot，再产品化

阶段动作验证指标
0–30 天5–10 家本地商家，人工辅助 onboarding，每周 2–3 个 campaign。是否愿意输入想法、审核内容、连接 Facebook、正式发布。
30–60 天Facebook official publish + attribution report。approve rate、publish completion、calls/DMs/coupon signals。
60–90 天收费 pilot / renewal conversation。是否愿意付 $99–299/mo 或 setup fee。

第一批 vertical

HVAC / home service、餐馆、salon/beauty、clinic/wellness、本地零售、华人商家。Aurora HVAC 可自用。

价格锚点

  • Starter: $49–99/月
  • Growth: $149–299/月
  • Done-with-you setup: $500–1500
  • Agency/VA 替代：$500–5000+/月

最大风险与对策：风险不是技术，而是 outcome + trust

风险为什么危险对策
商家不愿意连接官方账号没有官方发布，闭环断掉。Facebook first + 明确权限说明 + owner approval + 可 revoke。
商家不持续审核workflow 留存失败。weekly autopilot、手机一键 approve、少而准的内容包。
AI 内容 generic会被认为是 spam，和 Predis/Canva 无差别。行业 playbook、买家语言 mining、商家历史内容/评论学习。
没有明显业务结果客户试用但不付费。轻量 attribution 先跑：URL/QR/coupon/call/message，不等完美集成。
平台 API 权限复杂延迟真实发布。Facebook official path 先打通；TikTok draft/assisted；XHS deferred。
命名冲突Polsia LocalPilot 已出现，外部传播有风险。pilot 前评估改名或准备备选 brand。

Co-founder 需要一起拍板的问题

战略问题

  1. 是否同意核心不是内容生成，而是本地营销闭环？
  2. 是否 Facebook first，而不是同时做四个平台？
  3. 外部 pilot 前是否改名，避开 LocalPilot 命名冲突？
  4. 先 service-assisted pilot，还是直接 self-serve SaaS？

产品问题

  1. 第一批 vertical 选 HVAC、餐馆、salon、clinic 还是华人商家？
  2. Attribution MVP 到什么程度才够？URL/QR/coupon/call click 是否足够？
  3. 老板审核入口用 email、SMS、WhatsApp 还是 app 内？
  4. 每周生成多少内容，才不会让老板觉得负担更重？

建议默认答案

Facebook first；HVAC + 餐馆 + salon 三类 pilot；先 service-assisted；attribution 从 unique URL/QR/coupon/call click 开始；外部 pilot 前准备新名字。
