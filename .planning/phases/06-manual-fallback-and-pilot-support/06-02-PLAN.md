## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator session -> admin namespace | Only operator/owner sessions (or localhost dev) may access admin surfaces |
| admin response -> operator | Operator surfaces must never expose tokens, secrets, or raw provider payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-01 | Elevation of Privilege | admin namespace | mitigate | Gate every admin route via `resolve_operator` (owner/operator role) with explicit 403 |
| T-06-02-02 | Information Disclosure | operator diagnostics | mitigate | Reuse already-redacted `serialize_debug_publish_job`; pass all output through redaction |
| T-06-02-03 | Tampering | operator actions | mitigate | Retry reuses vetted publish paths; mark-support only appends a redacted event, never edits secrets |
</threat_model>
