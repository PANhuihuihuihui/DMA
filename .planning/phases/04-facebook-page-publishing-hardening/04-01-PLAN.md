Interface contract this plan establishes (consumed by 04-03):
- `token_crypto.encrypt_secret(plaintext: str) -> bytes` — returns Fernet ciphertext token (never equal to plaintext bytes).
- `token_crypto.decrypt_secret(ciphertext: bytes) -> str` — inverse of encrypt_secret.
- `token_crypto.resolve_key() -> bytes | None` — returns the Fernet key from `LOCALPILOT_TOKEN_KEY`, or `None` when absent.
- `token_crypto.is_production() -> bool` — true when `LOCALPILOT_ENV` == "production".
- When `resolve_key()` is None and `is_production()` is True → `encrypt_secret`/`decrypt_secret` raise `TokenEncryptionError`. When None and not production → callers may use the insecure in-memory fallback (the fallback itself lives in the vault, plan 04-03), but `token_crypto` must expose a boolean (e.g. `encryption_available()`) so the vault can branch and log the `INSECURE: token encryption disabled` warning.
</context>
