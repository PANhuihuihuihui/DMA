## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → backend APIs | UI calls connect/select/switch/publish/retry; must not expect or render tokens |
| OAuth redirect → SPA | `connectSession` arrives as a URL param; used only to fetch the picker list |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | UI rendering of connection/pages | mitigate | UI renders only redacted health + Page metadata returned by the backend; never requests or displays token material |
| T-04-08 | Elevation of Privilege | client-side publish gate | mitigate | Disabled publish button is UX only; the authoritative ACCT-03 gate is the server 409 in 04-05 (UI must not be the sole gate) |
| T-04-SC | Tampering | dependencies | accept | No new UI dependency added; reuse existing styles |
</threat_model>
