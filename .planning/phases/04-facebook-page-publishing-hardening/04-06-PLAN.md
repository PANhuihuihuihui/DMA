<objective>
Extend the Facebook publisher to publish link posts and single-image posts from the approved snapshot, and validate media against Facebook requirements before a publish job is created. Unify the Graph API version to v25.0.

Purpose: FB-03 (publish link/media when validation passes), MEDIA-03 (validate Facebook media before creating a job), MEDIA-05 intent (actionable validation errors), and D-12/D-13/D-14 (link + single image only; spec validation pre-job; deliver by public URL). Fixes the v20.0/v25.0 drift noted in RESEARCH.md. FB-02 text path is preserved.
Output: media validation + image/link publishing in `facebook_publisher.py`, with tests using the existing `opener`/`graph_base` seams.
</objective>

Existing seams: `publish_approved_snapshot(snapshot, user_token, page_id, publish_mode, scheduled_publish_time, graph_base, opener=None)` currently posts `{message}` to `{graph_base}/{page_id}/feed`. `build_facebook_message(snapshot)` joins caption/body/cta. `GRAPH_API_BASE = "https://graph.facebook.com/v20.0"` (MUST become v25.0). `graph_request(method, url, token, body, opener)` handles POST/GET + error classification (`FacebookProviderError`, `provider_diagnostics`, `classify_error_class`). The approval snapshot carries `mediaRefs` (each: `{id, kind, storageMode, storageRef, altText}`) and may carry a link (snapshot `link` or a media ref of kind `link`). `queue_facebook_publish` is the single entry point and already builds events/attempts.

Decisions: single image + link only (D-12); validate type {jpg,jpeg,png,gif} + size <=10MB + URL reachable (D-13); deliver image by public URL using `storageRef` (D-14). Multi-photo/video are OUT.
</context>
