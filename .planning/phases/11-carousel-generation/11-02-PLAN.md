<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> `/api/v1/generation/jobs` | Untrusted URL and source metadata can try to reach local networks or inject unwanted brand fields. |
| backend -> public website | Fetching third-party pages introduces SSRF, timeout, and noisy-content risks. |
| backend -> MiniMax chat extraction | Extracted content must stay content-only and must not become a side channel for saved brand data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Spoofing | `website_crawl._validate_public_url` | mitigate | Reuse the existing public-URL validation and private-network rejection path before any fetch occurs. |
| T-11-02-02 | Tampering | `extract_carousel_story_brief` | mitigate | Limit extraction output to content-only fields and ignore any URL-derived style fields before prompt or creative materialization. |
| T-11-02-03 | Denial of Service | page fetch and LLM extraction | mitigate | Reuse fetch byte limits, HTML truncation, and limited-source fallback so weak pages do not stall the job loop. |
| T-11-02-SC | Tampering | npm/pip/cargo installs | accept | No new package-manager installs are planned; reuse stdlib HTTP plus current repo dependencies only. |
</threat_model>
