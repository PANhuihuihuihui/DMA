# Scribe Workflow Extraction

Source: `Creating AI-Generated Creator Style Videos on Predis ai`

The Scribe page reports a 58-step, 32-minute workflow. The direct HTML fallback exposed the actionable steps; the Jina reader fallback was unavailable from this network.

## Core Flow

1. Start from Predis `Inspirations`.
2. Review UGC Ads, Image Ads, trending collections, and short-video filters.
3. Click Create New.
4. Choose the creator-style video option: make creator-style videos using AI-generated actors.
5. Describe the UGC video.
6. Use `Generate ideas for me`.
7. Enter product/offer intent, then a sales goal.
8. Continue through the wizard.
9. Choose a tone/style, with `Motivational` shown in the reference flow.
10. Choose an AI actor/avatar.
11. Choose a visual/template.
12. Continue through final review.
13. Generate the video.
14. Open the generated output.
15. Publish, choose destination, continue, then schedule.
16. Manage the result from Content Calendar.
17. Manage setup from Brand & Social Accounts, FAQ, Brand Details, Timezone, Content Settings, Exports, and Integrations.
18. Review performance from Analytics and help/support surfaces.

## Product Implications For LocalPilot

- The Create New entry should not be a generic form; it needs a guided creator-video wizard.
- Ideas must be generated by backend state, not only frontend text.
- The generated video should produce backend artifacts:
  - creative record
  - media asset/storyboard record
  - UGC voiceover package
  - calendar slot
  - publish draft metadata
- The flow must stay demo-safe:
  - no unapproved publishing
  - no fake external provider claim
  - no browser automation or scraping path
  - official account connection remains a prerequisite for real publishing
